# 校园学习待办

一个入门级的 AI 辅助编程演示项目，用于记录作业、复习和阅读等校园学习任务。

## 功能

- 输入任务名称，点击“添加任务”或按回车添加。
- 勾选任务，切换完成与未完成状态；已完成任务显示删除线。
- 删除单个任务。
- 筛选全部、未完成、已完成任务。
- 显示所有任务中尚未完成的数量，不受筛选影响。
- 使用 localStorage 保存任务及完成状态，刷新或重新打开后恢复。
- 拒绝空白任务，以纯文本安全显示输入。
- 没有任务或当前筛选无结果时显示简短提示。
- 简洁的中文界面，适配电脑和手机屏幕。

## 技术栈与设计思路

仅使用原生 HTML、CSS、JavaScript。HTML 提供页面结构，CSS 实现白色卡片、浅色背景与蓝色主题，JavaScript 处理添加、勾选、删除、筛选和计数。

任务以数组维护，通过 localStorage 保存到当前浏览器。无需后端、数据库、安装依赖或构建工具，不使用外部 API、CDN、在线字体或外部图片。脚本以普通脚本方式加载，文件通过相对路径引用，支持离线打开。

用户输入通过 `textContent` 显示，不拼接进 `innerHTML`。存储读写有异常处理；保存失败时页面会提示。

## 使用方法

1. 下载项目全部四个文件，放在同一文件夹中。
2. 双击 `index.html`，使用浏览器打开。
3. 输入学习任务，点击“添加任务”或按回车，即可开始使用。

不需要安装任何东西，也不需要启动服务器。

## 局限

- 数据只保存在当前浏览器，不支持跨设备、跨浏览器同步。
- 清除浏览器网站数据或隐私模式结束后，任务可能丢失。
- 直接打开本地文件时，localStorage 的行为由浏览器决定；建议始终使用同一浏览器、同一路径打开。移动文件后，原有数据可能不会出现。
- 如果浏览器禁用本地存储或存储空间已满，仍可临时操作，但刷新后可能丢失未保存的改动。
- 没有登录、注册、日历、提醒、云同步或 AI 对话功能。
